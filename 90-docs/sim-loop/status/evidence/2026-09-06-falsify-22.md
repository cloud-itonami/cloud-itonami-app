# falsify-22 (2026-09-06) — 「falsify-21 の 39.03 GiB 上界は branch 参照で回収可能」説の反証試行

## 主張 (反証対象)

falsify-21 の上界 39.03 GiB (3065 unused keys) は、branch 参照精査の結果
実際に drop 可能である (回収可能)。

## 測定 (実測のみ、推定なし)

- 対象: `~/github/com-junkawasaki/orgs/cloud-itonami/cloud-itonami-dns-resolver`
  (falsify-20 で増加源と同定された .git/annex 71G のリポ)
- 手法: `git annex unused --used-refspec <refspec>` を branch 別に実行し、
  key 行数 (`^[0-9]+\s+MD5`) と key 名埋め込みサイズ (`sNNNN--`) を集計。

| refspec | unused keys | 合計サイズ (bytes) |
|---|---|---|
| `+refs/heads/main` | 3088 | 42,199,579,172 (39.30 GiB) |
| `+refs/heads/HEAD` (detached 51d4010c) | 3088 | 42,199,579,172 |
| `+refs/heads/manifest-rev` | 3088 | 42,199,579,172 |
| `+refs/heads/resident/dns-resolver` | **0** | 0 |
| `+refs/heads/*` (全 branch 走査) | **0** | 0 |

## 結論: REFUTED

- 全 branch (`+refs/heads/*`) 走査では unused 0 — 39.30 GiB 全体が
  少なくとも 1 つの local branch 参照に保持されており、
  `dropunused` による一括回収は不可能。
- falsify-21 の「main-refspec 上界 39.03 GiB」は今回実測 39.30 GiB と
  微増 (世代増加継続、annex info keys 5951 と整合)。
- unused 集合が HEAD / manifest-rev / main で同一 (3088 keys) であること、
  resident/dns-resolver では 0 であることから、滞留世代は
  detached HEAD (51d4010c, manifest-rev 由来) 系の参照に保持されている。
- 回収には「manifest-rev / detached HEAD の参照解放 (git-annex dead /
  branch 削除 / expire)」が前提であり、データロス判断を伴うため Tier 2 のまま。
- 附帯実測: df avail 4557 MiB → 4578 MiB (100% 表示継続、微回復)。
