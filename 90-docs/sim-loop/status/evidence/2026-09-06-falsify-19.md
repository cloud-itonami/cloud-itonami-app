# falsify-19 (2026-09-06)

## 対象説 (falsify-18 の残余課題 NEXT-8)

「5.2Gi → 回復後の再飽和増分は m365-archive/onedrive (133G) の継続増加による」説、
およびその対偶「onedrive 以外の隠れ増加源による」説のどちらかを du 実測で判別する。

## 実測

- df (開始時): /System/Volumes/Data 100% / avail 2.8Gi (falsify-18 の 5.2Gi から -2.4Gi)
- du -sk 実測:
  - orgs/gftdcojp/m365-archive/onedrive = 139,771,548 KB = **133.3 GiB**
    (falsify-18 の 133G と同一水準 → 24h で増加ゼロ)
  - orgs/gftdcojp = 153,804,808 KB = 146.7 GiB
  - orgs 全体 = 315,606,848 KB = 301 GiB
  - /private/tmp/mt-sim-loop = 23.5 MB、/private/tmp/mt-merged-main = 1.8 MB
  - ~/.hermes = 14.3 GiB
  - /private/var/db/diagnostics = 2.6 GiB
- ~/Library の du は TCC (Operation not permitted) で部分的に遮断 —
  全域 attribution は本セッションでは不可能

## 判定

- 「増分は onedrive の継続増加」説 → **REFUTED** (onedrive 不変 133.3 GiB 実測)
- 「隠れ増加源」説 → **未確定** (TCC 遮断で全域 du 不能、-2.4Gi の帰属は測定不能)。
  排除済み: onedrive、mt-* worktrees (合計 25MB)、var/db/diagnostics は
  2.6GiB 存在するが 24h 増分の実測なし。

## 結論

- リスク-5 は 3 度目の飽和観測 (1.9Gi → 5.2Gi → 2.8Gi) で再発性が再確認された。
- 増分の機械的帰属には (a) 時点比較可能な定期 du snapshot または
  (b) operator による TCC 許可が必要 → いずれも Tier 2 提起。
- 帰属未確定のまま主張を伸張しない。maturity.md の記述は
  「onedrive は安定、増分帰属未確定」に範囲修正。
