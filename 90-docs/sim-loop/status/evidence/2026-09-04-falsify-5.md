## 反証の成立 (新 OPEN 赤)

`launcher_test.clj:122 leftover-jvm-aliases-are-gone` は PR #270 (4e607f6,
「leftover JVM aliases deleted」) 由来の契約テストで、:server/:mcp の不在を
要求する。しかし deps.edn は 6a85048 で :server/:mcp を**復活**させており、
その根拠は同ファイルの実測コメント (launchd plist が `-M:server` を指し、
alias 無し release からの再起動は run-path verifier
scripts/verify-itonami-run-path.cljs の configured-launch-alias-absent で brick)。

→ テストが主張する世界 (aliases 無し) は、測定済みの運用制約 (aliases 必要)
と矛盾。2 つの独立 checkout で同一赤が決定論的に再現。
最小 repro: `clojure -M:test` (main bfd158b) → launcher_test.clj:125-126 FAIL。
修理案 (Tier 2 report):
- 案 1: テストを現行契約に合わせ改訂 — `:server/:mcp` 存在 + run-path verifier
  が configured-launch-alias-absent を出さないこと、を併せて assert する。
- 案 2: テスト名と対象を「nbb host が live になったら aliases は消せる」の
  逆さガードに書替え (deps.edn コメントの flip 条件と束縛)。
帰属: #270 を着地させた agent と 6a85048 を着地させた agent の契約不一致。
