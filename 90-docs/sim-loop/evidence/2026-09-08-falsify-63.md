### 3. 根因: identity.clj の ns 形式破損 (679572b migration が :import opener を削除)

`git show 5e3aac9:src/cloud/itonami/app/identity.clj` (破損前):

```
            [oauth.model :as oauth])
  (:import [java.net URI URLEncoder]
           [java.net.http HttpClient HttpRequest HttpRequest$BodyPublishers
            HttpResponse$BodyHandlers]
           [java.nio.charset StandardCharsets]
           [java.security MessageDigest SecureRandom]
           [java.time Duration Instant]
           [java.util Base64 UUID]
           [java.util.concurrent TimeUnit]))
```

`git show 679572b:src/cloud/itonami/app/identity.clj` (現 tip、破損後):

```
(ns cloud.itonami.app.identity
  "docstring"
  (:require [...]
            [cloud.itonami.app.http-client :as http]   <- 追加
            [oauth.model :as oauth])
           [java.nio.charset StandardCharsets]
           [java.security MessageDigest SecureRandom]
           [java.time Duration Instant]
           [java.util Base64 UUID]
           [java.util.concurrent TimeUnit]))          <- 5 本の java ベクタが :import 無しで裸
```

**migration コミット 679572b が `(:import` opener と最初の 2 行
(`[java.net URI URLEncoder]` / `[java.net.http ...]`) を削除した際、残り 5 本の
`[java.* ...]` import ベクタを裸 (ns 直下の clause として) に取り残した**。ns 形式は
`(:require ...)` の後に `(:import ...)` の clause を持つべき所、clause ではない裸ベクタが
続き、`:ns-clauses` spec が fail (java.nio.charset が keyword clause 開始でない) → 即構文死。
