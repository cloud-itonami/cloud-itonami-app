は崩壊し、帰属議論はモーメンタムを失う。

## 判定

- 主張「滞留は増加継続下で生存し resident 帰属が不変」→ **REFUTED (帰属対象の消滅)**。
  滞留 (unused) は falsify-31 の 3427 keys / 43.99 GiB → **最終 14.67 MB (実質 0)** へ
  崩壊し、local annex は 6313 keys / 80.82 GB → **1 key / 14.67 MB** へ略空。
  avail は 50 Gi → 166〜192 GiB。増加源 (export_and_sync) も消失。
  **falsify-25/26/28/29/30/31 が提起してきた Tier 2 回収条件「resident ツリーからの
  旧 ingest 世代削除 / dropunused」が operator によって着地した**と直接観測。
  帰属議論の前提 (滞留の継続増加) は崩壊し、以後の増加観測は 0 ベースに戻る。
- `git annex information` reference: 滞留が存在しないため、滞留の resident 帰属
  (unused ∩ resident) は判定不能 = 議論そのものが役目を終えた。
