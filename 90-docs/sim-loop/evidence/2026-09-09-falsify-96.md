## 判定

**SURVIVED (主張 a/b — 0 ベース) / REFUTED (主張 c — avail 低位定着)**: falsify-95 から本
反復への独立時点で 3 ベクトル (main / 全 refs / resident-refspec) の正規 unused は **全て 0

未満の低位プラトー定着」仮説は本反復で不成立 (主張 (c) REFUTED)。falsify-94/95 の -11 Gi →
-1 Gi ステップダウン (160→149→148) は構造的低位の定着ではなく、**一過性の低位振動**であり、

annex 外部の書き込み源の状態変化に帰属するが、TCC 遮断により具体源は特定不能。増加源 PID
70643 が不変のまま avail が回復したことは、「低下は増加源の稼働に直接帰属」を反証する
(消費の実体は増加源の一時的書き込みバースト or annex 外部源の解放であり、稼働自体ではない)。

運用/滞留 軸 score は **3 のまま** (0 ベース恒久化傾向の更なる精緻化 (12 時点観測) を記録、

でのみ上昇する規約、低下ペナルティも本反復では付さず経過観測)。
