## 判定

**SURVIVED (主張 a/b — 0 ベース) / REFUTED→再アンカー (主張 c — avail)**: falsify-110 から
本反復への独立時点で 3 ベクトルの正規 unused は全て 0 のまま、local annex keys は
786 → 786 (増加 0、17 時点観測 / 16 反復連続維持) — 主張 (a) 再出現も (b) 再蓄積も
検出されず、falsify-110 指定の閾値「16 反復超の連続持続」を充足し 0 ベース恒久化傾向を
更に精緻化した。

他方、**avail は df 34789 → 193392 MB (≈ 34.0 → 188.9 Gi)、annex 36.38 → 203.15 GB と
約 +154.9 Gi / +166.8 GB の帯外上方回復**を観測 — 主張 (c) 成立 (「34 Gi 前後 ±1 Gi
ブレ」帯は帯外逸脱し REFUTED)。逸脱方向は上方回復で、falsify-107 の -78 Gi 急落と
対称の大幅ジャンプ。local annex keys 不変ゆえ回復は annex 外部 (外部解放源)。緊急フラグ
(<100 Gi) は解除、structural-decline-monitor は緊急観測モード解除し通常観測へ戻す。
観測系列 113.9 → 34.5 → 34.7 → 34.0 → 188.9 Gi は「低帯ブレ」でも「漸次減退」でもなく
**GB 十台級 ( Gi 十台級) の外部源起因ステップ変動**の様相を強め、定着帯アンカーの
信頼性自体が低下 — 監視は「帯アンカー」から「単時点実測値の忠実記録 + 大幅変動
(±10 Gi 超/反復) の検知」へ簡素化する (3 反続で 3 回破れた定着帯アンカー枠組みの
範囲修正)。

運用/滞留 軸 score は **3 のまま** (0 ベース 16 反復超連続維持を記録。avail は大幅回復を
観測したが score に影響する新規の実装/緑測定変化はなく、実緑測定でのみ上昇する規約)。
