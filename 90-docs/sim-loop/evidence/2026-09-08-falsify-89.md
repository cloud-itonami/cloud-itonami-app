## 判定

**REFUTED (主張 a/b とも不成立) / 0 ベースは 4 反復超の連続維持へ達し「恒久化傾向」へ精緻化**:
falsify-88 から本反復への独立時点で 3 ベクトル (main / 全 refs / resident-refspec) の正規
unused は **全て 0 のまま**、local annex keys は **786 → 786 (増加 0, falsify-85→89 の 5 時点
観測で 4 反復連続維持)**、既知 partial 14 chunk のみ — 主張 (a) の再出現も (b) の再蓄積も検出
されなかった。増加源 (resident PID 70643) はしっかり稼働継続しているが、新規 key を参照させる
滞留を積まない状態が 4 反復 (観測 5 時点) にわたり維持されている。

**範囲精緻化**: falsify-88 が指定した閾値「0 ベースの **4 反復超の連続持続 → 恒久化傾向へ
精緻化**」を本反復が充足 (falsify-85 回帰直後から 86/87/88/89 の 4 反復連続で維持、観測期間
としては 5 時点跨ぎ)。回収は falsify-88 の「恒久化の兆し」ステージから**「恒久化傾向」**ステージへ
精緻化した。ただし falsify-32→33 が示したとおり 0 ベースの恒久性は保証されておらず、増加源
(PID 70643) 稼働継続のため再蓄積の可能性は引き続き残る — 本 REFUTED/SURVIVED は
「以後も never re-accumulate」を主張しない。継続観測対象: 次反復以降も同 3 ベクトル + local
annex keys + avail を再実測し、0 ベース維持が更に持続するか (5 反復超の連続維持)、および
df avail の減少 (-14Gi) の帰属を観測 (avail は 162→156→142 Gi と 2 連続で減少中なため、その
帰属を次反復の観測対象に加える)。

運用/滞留 軸 score は **3 のまま** (0 ベース維持の継続化・恒久化傾向への精緻化を記録、
