## 判定

- 主張「帰属は生存する」→ **SURVIVED**。unused は増加継続
  (3311→3348→3372→**3385** keys / 42.41→42.93→43.27→**43.44** GiB)
  しつつも、その全件 (3385/3385 = 100%) は resident 現在ツリーに参照され、
  falsify-25/26/28 の帰属不変条件は維持。detached HEAD / 他 branch 由来の
  滞留は intersection 外 0 を再実測。増加レートは ~+13 keys / +0.17 GiB
  (falsify-28 の +24/+0.34 よりやや低いが、傾向は継続)。
- 主張「ディスクは avail 低位で再飽和継続」→ **CONFIRMED** (反証に耐える):
  avail は反復内で 1.50→1.48 GiB (約 5 分で -20 MB) と減少継続、falsify-28
  の 3.3Gi 台から再び 1.5Gi 台へ低下し、増加源 (resident ingest) は停止の
  形跡なし。リスク-5 (再発性ディスク飽和) は継続。
