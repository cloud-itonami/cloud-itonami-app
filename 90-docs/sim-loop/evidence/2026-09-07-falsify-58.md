## 判定

- **主張「09:00 発火後も未修理のまま失敗し続ける」→ SURVIVED**。job は 2026-09-07
  09:00 に実際に発火 (runs 0→1) し、last exit code = 1 / not running、log に
  `Could not find namespace: authority.scope` を再発行。修理案 A (classpath 3 src 追加)
  は着地されていない。
- **帰属確定**: 失敗はロードパス classpath に authority/src を含めない plist 不備の
  単独原因 (falsify-9/11/17/18 継続)。ソース (scope.cljc) は存在するため、「無い機能を
  読もうとした」のではなく「ある機能を classpath に入れ忘れた」。
- 範囲修正済み: falsify-18 の「plist は再 bootstrap 待ちで発火履歴 0」は本反復で
  falsify-58 により**発火済み (runs=1)** へ更新。赤-2 の実体は「一度も実行されていない」
  から「毎発火ごとに classpath不備で失敗する」へ精緻化。
