### 6. 実行時可用性 (本ホストの docker 欠如 — 「未活性」の正体)

```
command -v docker  →  docker ABSENT on host
```

→ `virtual-shell/available?` の 3 条件 (docker-bin 実行可 / `docker info` 成功 /

## 判定

- **主張「virtual-shell は未活性」→ REFUTED (全面主張としては)**。virtual-shell は
  実装・ライブディスパッチ・write ゲート・describe・テスト (5 deftest) を完備し、
