## 主張 (falsify-25 の帰属が増加後も成立するか)

falsify-25 は「main-refspec の unused 集合 (当時 3286 keys) は
resident/dns-resolver の *現在ツリー* から 100% 到達可能」と測定した。
滞留は増加継続中 (falsify-24/25) であるから、この帰属が今も成立する
(=新規増加分の key もすべて resident 現在ツリー参照内に収まる) ことを
再び機械集計で検証する。属する反証: 「残留世代は resident ツリー外の
何か (他 branch / detached ref) に由来する」は誤り — 滞留は今も
resident 現在ツリーが唯一の参照元。

## 判定

- 主張「unused 3311 keys は resident 現在ツリーから 100% 到達可能」→
  **SURVIVED** (機械集計 3311/3311、unused−resident = 0)。
- 帰属は falsify-25 の通り確立: 滞留は resident branch の現在ツリー
  (data/ledger/ 配下 .edn 世代) が参照。他 branch / detached ref /
  droppable ことはない。滞留は「main refspec からは未参照だが
  resident 現在ツリーからは参照される ingest 世代」として継続増加。
- 附帯: avail 2.03 GiB / 100% に再飽和 — falsify-25 (12.1 GiB) より
  さらに逼迫。増加源は稼働継続のまま複数回の再飽和を観測 (falsify-17/19/20/26)。
