## 判定

**SURVIVED (帰属不変 + 増加継続)**
- main-refspec 正規 unused は **456 keys / 6.41 GiB** (falsify-48 の 444 keys / 6,699,301,080 bytes
  から **+12 keys / +185,300,766 bytes ≈ +0.17 GiB**)。falsify-48 は「2 反復跨ぎ +50 ≈ +25/反復」、
  本反復は単反復で **+12** と増加は継続 (単反復レートは ~12〜62 の間で振動、単調ではない)。
- resident-refspec 正規 unused = **0** → 滞留の全件が resident 現在ツリー参照 (unused ⊆ resident、
  unused−resident = 0)。falsify-25 以来の帰属が 456-key / 6.41 GiB スケールで生存継続。
- 全 refs 走査 (refspec なし) の正規 unused = **0** → main-refspec で unused 判定された key のうち
  いかなる ref からも到達不能な孤児は存在しない (falsify-46/48 の独立ベクトルを再確認)。
- partial chunk は **14 → 14** / 186,977,095 bytes で不変 (falsify-35 の 1 chunk 解決以降
  **連続 13 反復 drift なし**、間欠的のまま)。
- df avail 136Gi / 85%、100% 飽和解消のまま (falsify-48 の 140Gi から -4Gi 漸減)。
