## 判定

**REFUTED (主張 a/b/c とも不成立) / 0 ベースは 5 反復超の連続維持へ達し「恒久化傾向」を
更に精緻化・avail の減少トレンドは成立せず**:
falsify-89 から本反復への独立時点で 3 ベクトル (main / 全 refs / resident-refspec) の正規
unused は **全て 0 のまま**、local annex keys は **786 → 786 (増加 0, falsify-85→90 の 6 時点
観測 / 5 反復連続維持)**、既知 partial 14 chunk のみ — 主張 (a) の再出現も (b) の再蓄積も
検出されなかった。増加源 (resident PID 70643) は稼働継続のまま、新規 key を参照させる滞留
を積まない状態が 5 反復 (観測 6 時点) にわたり維持されている。avail は 142→159 Gi へ反発
し、主張 (c) の 3 連続減少トレンドは成立しなかった (162→156→142→159 の振動)。

**範囲精緻化**: falsify-89 が達成した「恒久化傾向」(0 ベース 4 反復) を、5 反復連続維持
(観測 6 時点跨ぎ) へ更に精緻化。0 ベースの恒久性は依然保証されず (falsify-32→33 exemplar)、
増加源 (PID 70643) 稼働継続ゆえ再蓄積の可能性は残る — 本 REFUTED/SURVIVED は「以後も never
re-accumulate」を主張しない。**avail の 2 連続減少トレンドは REFUTED (振動と帰属修正)**:
滞留量 (keys 786) が不変である以上、avail の大幅振動 (±17Gi) は annex 滞留ではなく外部
書き込みに帰属するのが整合的。継続観測対象: 次反復以降も同 3 ベクトル + local annex keys +
avail を再実測し、0 ベース維持が 6 反復超へ持続するか、および avail 振動の帰属 (外部書き込み
源) を観測。

運用/滞留 軸 score は **3 のまま** (0 ベース維持の継続化・恒久化傾向の精緻化を記録、
green 化測定/実緑の裏付けは本反復では得られない — score は実緑測定でのみ上昇する規約)。
