## 判定

**REFUTED — falsify-33..53 の「滞留は反復ごとに再蓄積する現在形継続」という語調は
点時刻として不成立 (unused は 3 ベクトル全てで 0)**: 主 anchor falsify-53 (651 keys /
9.7 GB) から、超越期間 (実装/governor/spec 軸 3..8 反復) を跨いだ独立測定で
main/full/resident 全 refspec の正規 unused が **0 keys** を実測。falsify-32 の
「dropunused 着地後 0 ベース」と同型の状態へ回帰しており、この間 (a) 長期 Tier 2 提案
「resident ツリーからの旧 ingest 世代削除」が operator に着地、または (b) resident
プロセス再起動 (PID 94682→70643) に伴う参照再構成、のいずれかで滞留が回収された
可能性が高い (直接の dropunused 呼び出し履歴は本 bot からは観測不能のため単一帰属は
未確定)。

**範囲修正 (重要な留保)**: falsify-32→33 が示したとおり、(a)/(b) の 0 ベースは恒久解消で
なく 40 分程度で再蓄積し得る。本反復の REFUTED は「この点時刻で unused=0 であり、継続再蓄積
という『現在形が常に成り立つ』は偽」に限定され、再蓄積可能性の除去を主張しない。増加源に
あたる resident プロセス (PID 70643) は稼働継続しているので、次反復以降で re-accumulation
が再開するか注視する。リスク-5 (ディスク飽和の構造リスク) は本測定では実証されず
(avail 163Gi / 9%)、100% 標示も現時点でなし。

運用/滞留 軸 score は **3 のまま** (滞留の継続再蓄積語調の反証 + 0 ベース回帰の記録であり、
green 化測定/実緑の裏付けは本反復では得られない — score は実緑測定でのみ上昇する規約)。
