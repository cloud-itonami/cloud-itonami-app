## 判定

**SURVIVED (主張 a/b — 0 ベース) / REFUTED (主張 c — avail 減退継続 / 150 Gi 未満再ドロップ)**:
falsify-99 から本反復への独立時点で 3 ベクトル (main / 全 refs / resident-refspec) の正規 unused
は **全て 0 のまま**、local annex keys は **786 → 786 (増加 0, falsify-85→100 の 16 時点観測 /
15 反復連続維持)**、既知 partial 14 chunk のみ — 主張 (a) の再出現も (b) の再蓄積も検出されず、
falsify-99 指定の閾値「15 反復超の連続持続」を充足し 0 ベース恒久化傾向を**更に精緻化**した。

他方、**avail は df 実測 156 → 156 Gi (不変)、annex available 167.72 → 166.88 GB (約 -0.84 GB
微減・減速) と、150 Gi 未満には再ドロップしない** — 主張 (c) の「緩慢減退トレンド継続による
150 Gi 未満再ドロップ」仮説は本反復で発生せず (主張 (c) REFUTED)。さらに **falsify-99 が
「150 Gi へ向かう漸次的減退トレンド」へ再アンカーした系列 (159→159→158→156 Gi) は本反復で
156 → 156 Gi と初めて横這い**となり、単調減退の連続性が途切れた — 「減退トレンドが続いて
150 Gi に漸近する」という falsify-99 の予測も本反復の df 実測では成立せず、範囲修正として
avail は**「156 Gi で横這い (減退停止)、annex available は一等級減速した GB 級微減が続く」**へ
再アンカーする (structural-decline-monitor の再強化は見送り、再ドロップ or 減退再開時まで経過
観測)。temporary object 186.98 MB / 14 chunk 不変、滞留 (keys 786) / 11.68 GB 不変。増加源
PID 70643 不変のまま、消費は annex 外部の一時的書き込みバースト/外部解放に帰属継続 (TCC 遮断で
具体源特定は継続不能、operator の du 調査を Tier 2 継続)。

運用/滞留 軸 score は **3 のまま** (0 ベース恒久化傾向の更なる精緻化 (16 時点観測 / 15 反復
連続維持) を記録、falsify-99 指定の閾値「15 反復超」を充足 — score は実緑測定でのみ上昇する
規約、低下ペナルティも本反復では付さず経過観測。avail の減退停止 (df 横這い) は新規観測として
記録)。
