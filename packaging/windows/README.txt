Cloud Itonami 0.4.0 - Windows x64 preview

Requirements:
- Windows 10 or later
- Java 21 or later available as java.exe on PATH

Extract the complete "Cloud Itonami" directory, then double-click
CloudItonami.exe. The local server binds only to 127.0.0.1:1338 and opens the
web surface in Microsoft Edge application mode when Edge is available.

The preview is not Authenticode-signed. Automatic updates are accepted only
after the release manifest's Ed25519 signature plus package size and SHA-256
have all been verified.
