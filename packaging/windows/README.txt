Cloud Itonami 0.4.2 - Windows x64

Requirements:
- Windows 10 or later

Extract the complete "Cloud Itonami" directory, then double-click
CloudItonami.exe. The launcher starts the bundled server binary
(cloud-itonami-server.exe) directly and does NOT need or use a Java
installation. The local server binds only to 127.0.0.1:1338 and opens the
web surface in Microsoft Edge application mode when Edge is available.

Stable-channel builds are Authenticode-signed and timestamped. Automatic
updates require both the signed release manifest and the same Windows publisher
certificate as the current installation.
