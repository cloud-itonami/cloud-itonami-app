# reuse-operations

不用品回収・遺品整理・リユース／リサイクル事業の運営を支える Bot profile。受付、見積、配車、現場指示、品目追跡、再販在庫、収支、集客の下書きと継続管理を担当します。

## Itonami Bots で使う

1. 対象組織で新しい Bot を作り、名前を「回収・遺品整理・リサイクル運営」、brief に `BRIEF.md` の本文を設定します。
2. Bot に `SOUL.md` と `skills/reuse-case-operations/SKILL.md` を渡し、現在の profile を読んでからそれぞれ保存するよう指示します。Itonami の `profile_read` / `profile_update` による revision 照合を使い、既存 Bot の persona を無断で上書きしません。
3. SOUL の初回確認項目を埋めます。具体的な顧客、許可証、台帳、写真は私的な workspace や接続先で管理します。
4. 必要な顧客台帳、予定表、会計、メール、在庫・販売先を選び、その Bot の接続と操作権限を設定します。まず提供資料から受付票と見積下書きを作成して確認します。
5. 必要に応じて日次・週次の実行を設定し、実行結果と台帳の更新を確認します。

`config.yaml` は provider／model を固定せず、接続を含みません。既存の稼働環境で選択します。このディレクトリは、source profile の準備のみで、Bot 作成・インポート・権限付与・定期実行を行いません。`USER.md` / `MEMORY.md`、実案件、資格証、運用状態は host 側に保持します。

## 最初の依頼例

「対応地域と料金表、車両・人員、許可・委託先情報を渡します。不足項目を整理し、問い合わせ1件の受付票、見積下書き、作業指示書、品目台帳を作ってください。未確認事項は次の行動・担当・期限にしてください。」

制度確認の参考：環境省の [無許可回収業者に関する案内](https://www.env.go.jp/recycle/kaden/tv-recycle/qa.html) と [家電のリユース・リサイクル案内](https://www.env.go.jp/recycle/kaden/tvrecycle.html) を2026-10-13に確認。個別案件は所在地・排出元・品目に応じた最新の自治体情報と許可範囲を確認します。
