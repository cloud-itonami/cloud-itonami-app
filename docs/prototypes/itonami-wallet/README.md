# Itonami: wallet-first top-page prototype

itonami.cloud のトップでウォレット接続、BOT選択、購入・USDC Lendingの確認まで進める、日本語の静的UI改修案です。

## 動作する範囲

- Operations / Sales / Finance / People BOT の選択。
- ブラウザの注入型ウォレットへの接続要求と、アカウント・ネットワーク変更の表示。Base Mainnet以外ではその旨を表示します。
- BOT購入 / USDC Lending の切り替え、金額入力、確認ダイアログ。
- USDCの小数6桁を整数として処理する稼働予算シミュレーター。稼働日数は `floor(稼働予算 / 1日あたりの総費用)` です。
- モバイル向けレイアウトとキーボードによるタブ操作。

## 未接続の範囲

このページは取引や稼働を実行しません。価格、購入先、取得する権利、貸付先、コントラクト、利率、返済期日、担保、出金条件は未設定です。ウォレットの接続はログイン認証ではなく、署名・送金も要求しません。WalletConnectのQR接続は含みません。

Murakumoでの推論とKotobaseへの永続化は、運用設計を説明する表示のみです。バックグラウンド実行、ジョブ再開、支出制限、残高監視、支払い確認は実装されていません。

100 USDC・5 USDC/日は入力例であり、実際の価格や実績ではありません。購入代金、稼働予算、貸付元本は別管理とし、貸付希望額を稼働予算へ自動加算しません。元本を運営費に使う場合、返済原資と流動性管理を別途設計する必要があります。

## ローカルで開く

リポジトリのルートで以下を実行し、表示されたローカルサーバーのURLを開きます。

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory docs/prototypes/itonami-wallet
```

ビルドとパッケージのインストールは不要です。フォントはGoogle Fontsから読み込み、利用できない場合はシステムのsans-serifにフォールバックします。ウォレット接続には対応拡張機能、またはウォレットアプリ内のブラウザが必要です。

## 本番接続に必要なもの

1. itonami.cloudのトップを配信する実際のソースとデプロイ先への統合。
2. BOTの商品情報・価格・購入権利、チェーンとUSDCアドレス、決済先、決済確認API。
3. 貸付先、返済条件、資金使途、返済原資、契約情報と貸付・返済・出金処理。
4. Murakumo呼び出しとKotobase保存を行うサーバー側の実行基盤、認証、予算上限、重複実行防止、再開処理。
5. 本番化する接続・署名・取引フローのブラウザ検証とテストネットでの検証。

秘密鍵やAPIシークレットをブラウザコードに追加しないでください。

## 確認済み

JavaScript構文、最小単位（0.000001 USDC）、小数除算、負数・指数表記・小数7桁の拒否、署名・送金メソッドが含まれないことを確認しました。実ウォレットを使ったブラウザテストと本番統合テストは未実施です。
